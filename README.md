## 配色

首页画面下方可以选择「月白」「星雾」「深空」，点击颜色方块自由换色。
默认月白，不再固定深蓝。每个访问者的选择只保存在自己的浏览器。
可暂停动态效果，并尊重系统的减少动态效果偏好。

## 发布

这是一个无需安装依赖、无需服务器的静态网站。
在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main / (root) 并保存。
后续修改此仓库的 index.html、site.css 或 site.js 后，GitHub Pages 会重新发布。

## 隐私边界

仓库只有公开简介、GitHub / Google 学术链接、主题图片和静态网页。
不含私人数据库、登录模块、导师联系、健身数据、日程、密钥或备份。
GitHub Pages 不运行本地私人工作台，不自动同步本地新增或编辑的内容。
发布更多成果前，先确认内容可以公开，再更新本网站。

人物、仪器和星图为生成式艺术意象，非历史肖像或天文数据；寄语为本站原创。
